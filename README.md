# CIGO STUDIO Paint 6.3.0 — Profili pressione mouse

Versione incrementale basata sulla 6.2.9.

- Tre profili rapidi nel menu **Regolazioni artistiche**: Disattivata (0%), Naturale (45%), Espressiva (85%).
- Rimane disponibile il cursore per impostazioni personalizzate.
- Evidenziazione del profilo attivo; aggiornamento automatico dell’etichetta percentuale.
- Correzione dell’etichetta «Carico pigmento sfumino» precedentemente indicata erroneamente come «Gomme artistiche».
- Nessuna modifica al motore di disegno e alle funzionalità precedenti.

## Installazione
Estrarre lo ZIP e caricare il contenuto nella radice del repository GitHub Pages, sovrascrivendo i file precedenti.

## Collaudo consigliato
Con la matita 4B, confrontare tratti lenti e veloci nei tre profili; verificare anche il cursore manuale e il menu richiudibile.
