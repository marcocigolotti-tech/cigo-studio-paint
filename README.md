# CIGO STUDIO Paint 6.3.1 — Pressione mouse più espressiva

Correzione incrementale dalla 6.3.0.

- Escursione di pressione simulata ampliata (0.15–1.80 a 100%).
- Grafite: maggiore risposta del deposito alla pressione, preservando la grana.
- Carboncino: intensità più sensibile alla pressione.
- A 0% il comportamento è invariato.
- Non si tratta di pressione reale: la simulazione usa la velocità del mouse.

## Prova
Selezionare Matita 4B, pressione simulata 100%, e confrontare due tratti alla stessa dimensione: uno molto lento e uno rapido. Confrontare poi con 0%.

## Installazione
Estrarre lo ZIP e caricare tutti i file nella radice del repository GitHub Pages.
