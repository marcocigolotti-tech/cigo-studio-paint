# CIGO STUDIO Paint 5.5 — Menu strumenti

Aggiornamento della versione 5.4, con cinque gruppi di strumenti espandibili. Clicca un gruppo per scegliere lo strumento; il pulsante mostra quello attivo. In modalità Scuola restano visibili soltanto gli strumenti consentiti.

Conserva le funzioni di disegno, i livelli e il formato `.cigopaint` della versione precedente. Per GitHub Pages caricare `index.html`, `css/` e `js/` mantenendo le cartelle.

Ideato, progettato e creato dal Prof. Marco Cigolotti, con il supporto dell'intelligenza artificiale.
